# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a security vulnerability.

Report it privately through GitHub: on this repository, go to **Security → Report a vulnerability**
(GitHub Private Vulnerability Reporting). That channel reaches the maintainers directly and keeps
the details private while a fix is prepared.

If that channel is unavailable to you, open a regular issue titled "Security contact request"
with no technical details, and a maintainer will arrange a private channel.

## What to expect

- Acknowledgement of a report within 7 days.
- A fix or a mitigation plan for confirmed vulnerabilities, with critical issues prioritised.
- Credit for the reporter in the release notes of the fixing release, unless anonymity is requested.

## Supported versions

Security fixes are applied to the latest release. Older releases are not maintained.
